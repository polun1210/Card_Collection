# 臺銀請求模擬 Chrome 的 TLS 指紋，且解析同時認中英文牌告

匯率請求改走 **curl_cffi 並 `impersonate="chrome"`**，不與 SNKRDUNK 共用 httpx client。同時明確指定 `Accept-Language: zh-TW`，並讓 CSV 解析**同時認得「本行買入」與「Buying」**。

## Context

ADR-0014 記錄了臺銀有「間歇性的機器人保護」。第一次真實全量爬取（68 個卡種、1360 筆成交）證實了它不是間歇的：**臺銀掛的是 Akamai Bot Manager**，回應是 200、內容為 `Challenge Validation` 頁，其中的 `/E9XH25gq/vXXXR8p/...` 亂碼路徑是它的特徵。SNKRDUNK 那側全部成功，1360 筆成交完整入庫，但一筆都換不成台幣。

原本的實作讓匯率請求共用 SNKRDUNK 的 httpx client，因此只帶了一個 `User-Agent`——而且是宣稱自己是 Chrome 的 UA。**「自稱 Chrome、卻沒有 `Accept`、`Accept-Language`、`Sec-Fetch-*`」比不帶 UA 更可疑**，這正是 Akamai 要抓的訊號。

## Considered Options

**補齊瀏覽器 header**：實測有效，當場拿回 124 個營業日。但它只處理 header 層；Akamai 也看 TLS 握手指紋（Python 的 httpx 與 Chrome 長相不同）、IP 信譽與請求節奏，所以「今天通了」不保證明天通。

**手動匯入匯率 CSV**：使用者用瀏覽器下載那份 CSV 再匯入。完全不與反爬對抗，也最不會壞，但每半年要人工介入一次。

**換一個對程式友善的匯率來源**：TWD 的免費歷史匯率來源本來就稀少（ECB 的參考匯率根本不含新台幣），這正是 ADR-0014 最後選臺銀的原因。這條路不保證有出口，且需要再跑一次探測才能講，不能憑猜。

**模擬 Chrome 的 TLS 指紋**（採用）：由專案擁有者決定。取用的是公開的公營銀行牌告匯率、供個人使用、一次爬取最多一個請求，屬於合理的資料取用；`curl_cffi` 讓握手指紋與 header 組同時對得上，是三個選項中唯一同時處理兩層訊號的。

## Consequences

- **多一個依賴（curl_cffi）與多一套 HTTP 堆疊。** SNKRDUNK 維持 httpx，只有臺銀走 curl_cffi。
- **測試接縫因此往上移一層。** 全專案的測試一律在 httpx 傳輸層回放錄下的回應，但 curl_cffi 攔不到那一層，所以匯率的接縫是**下載器本身**（`create_app(fx_download=...)`）。`tests/test_fx_download.py` 是全專案唯一直接替換外部函式的測試檔，檔案開頭寫明了為什麼。
- **這個選擇無法用實測驗證它更耐擋。** 寫這份 ADR 時臺銀連補齊 header 的 httpx 都放行，所以沒有辦法製造出「httpx 被擋、curl_cffi 通過」的對照。採用它的依據是機制（多蓋住 TLS 指紋這一層），不是量測。這一點與本專案「實測，不憑猜」的慣例不同，必須說在前面。
- **臺銀升級偵測後照樣會壞。** 屆時的退路仍是手動匯入 CSV，那條路不依賴任何反爬對抗。

### 模擬瀏覽器帶來的語言副作用

`impersonate="chrome"` 會連同 Chrome 的 header 組一起送，其中包含 `Accept-Language: en-US`。**臺銀依此回英文版 CSV**：欄位位置與數值完全相同，只有方向欄從「本行買入」變成 `Buying`。

原本的解析器只認中文字串，於是會在**拿到真資料的情況下**回報「臺銀回應裡沒有任何日圓牌告」——這是被自己的反爬手段製造出來的安靜說謊。因此：

1. 明確送出 `Accept-Language: zh-TW`，讓語言是我們決定的，不是模擬目標決定的。
2. 解析同時認 `本行買入` 與 `Buying`。**不靠 header 來保證格式**——那是看不見的耦合，臺銀改一次預設值就整條鏈斷掉，而且不會報錯。

### 失敗必須說出實話

第一次真實爬取時，畫面顯示的是「1360 筆待審，原因：查無成交當日匯率」，但真相是「被機器人驗證擋下」。ADR-0014 白紙黑字警告過這個變體，實作卻讓它發生了——`FxRateService` 把 `FxRateError` 吞掉，原因沒有往上帶。

因此待審原因拆成兩個：**匯率來源暫時不可用**（這一輪根本沒拿到牌告）與**查無成交當日匯率**（該日期超出來源涵蓋範圍）。兩者都會在下一輪自動重試（ADR-0016），且來源恢復後前者會被更正成後者。爬取結果另外帶一個 `fx` 區塊，載明這一輪有沒有去抓、換算了幾筆、失敗原因是什麼。
