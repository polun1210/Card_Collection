# 髒資料採白名單策略，寧可漏抓不可污染

只收下能高信心確認為「單張、PSA 10、屬於此卡種」的成交紀錄，其餘一律進入待審佇列，不參與任何計算。

## Considered Options

黑名單（過濾已知垃圾、其餘全收）能抓到更多資料，但市值是**稀疏樣本的中位數**——在只有 5 筆成交的中位數裡混進 1 筆垃圾是毀滅性的，而漏抓 3 筆只是資料少一點。錯誤的數字不會報錯，只會安靜地錯下去。

## Consequences

即使 SNKRDUNK 提供 PSA 10 篩選，仍有三類髒資料是篩選器擋不掉的，必須另行處理：多張一組（API 的 `sizes` 有 1 枚～10 枚，總價會被誤當單張價）、下架但未成交（有價格不等於有成交）、離群值。
