# 走勢圖簡化為單條面積線

Status: Accepted  
Date: 2026-11-05

## Decision

首頁 Hero 的走勢圖改成**單條總市值折線＋同色垂直漸層面積**，畫面上拿掉：

- 底部的涵蓋率量尺（斜線區、涵蓋率階梯）
- 涵蓋率不足區段的虛線切段
- 總成本階梯線與其中間的色帶
- 圖例（`trend-legend`）
- hover 讀數裡的「涵蓋率」

保留：區間鈕（7D／1M／3M／YTD／ALL）、hover 的直立 guide 線與市值圓點、讀數裡的日期、
總市值、總成本。

圖的樣子：

- 線色與面積色是 teal（`--trend-line: #1FA99A`），定義在 `portfolio.css`（頁面層）。
  **不使用 `--positive`／`--negative`**：這條線講「總市值多少」，不是「賺賠」。
- 4 條水平點狀虛線格線，左側是格線數值，沒有縱軸線。
- 底部一條實線 x 軸，下方 4～5 個平均分布的 `M/D` 日期標籤。
- **縱軸不從 0 起算**：範圍取資料最小值到最大值，格線落在 1、2、5 × 10ⁿ 的整齊數字上。
  原本從 0 起算，是為了讓「市值線與成本線的空隙」與未實現損益成比例；成本線拿掉之後，
  這個理由就不存在了。

**資料與 API 不動。** `/api/portfolio` 的 trend 仍回傳每天的 `valued_kind_count`／
`held_kind_count`，ADR-0021 對涵蓋率的**資料定義**仍然有效，守它的測試原樣保留。
首頁 Hero 的「N 張沒有市值」也不動，那是總市值本身的揭露，不是走勢圖的一部分。

## Context

這是使用者看過參考圖之後的明確決定：「完全照參考圖，拿掉涵蓋率」以及「拿掉成本線，只留
讀數」。ADR-0021 當初要求圖上必須逐日揭露涵蓋率，本 ADR 推翻它**畫面上**的部分。

## Consequences

- **代價要老實寫：** ADR-0021 的衰減表（今天 68/68，一個月前 12/68，三個月前 5/68）
  說明，曲線前段的爬升有一部分是涵蓋率補齊造成的，不是行情。圖上不再標示這件事，
  讀圖的人會看不出來。這個風險是使用者接受的取捨。
- 緩解：總成本仍在 hover 讀數裡；涵蓋率仍在 API 裡；Hero 仍標明有幾張沒有市值。
- 以後要把涵蓋率加回來，**不需要動後端**，只需要改 `_portfolio_hero.html` 的 `draw()`。
- 縱軸不從 0 起算，視覺上會放大波動。單線圖沒有第二條線可以對照，這是這種圖的通性。
- `interface.md` §5 第 5 條改成指向本 ADR；ADR-0021 的狀態標為「畫面部分已被取代」。
