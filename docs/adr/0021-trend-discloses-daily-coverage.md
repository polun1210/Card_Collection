# 走勢圖逐日揭露涵蓋率

走勢圖的每一個資料點，除了總市值與總成本，一律並列兩個數字：**這天有幾個持有卡種
算得出市值**，以及**這天總共持有幾個卡種**。兩者的比值即**涵蓋率**。涵蓋率不足的
區段在圖上與足額區段視覺可分。

這是把 ADR-0015 對**單張卡的市值**採用的作法——不改定義、不隱藏資料、把樣本的形狀
寫在旁邊——延伸到**整條曲線**。

## Context

走勢圖逐日即時計算：某一天的總市值，是那天實際持有的卡種（ADR-0003）各自以該日
（含）以前的成交紀錄算出的市值（ADR-0002）之和。算不出市值的卡種不進總和。

問題在於，**算得出市值的持有卡種數隨日期回推急遽衰減**（2026-08-26 實測）：

| 時間點 | 算得出市值的持有卡種數 |
|---|---|
| 今天 | 68 / 68 |
| 一週前 | 33 / 68 |
| 兩週前 | 26 / 68 |
| 一個月前 | 12 / 68 |
| 三個月前 | 5 / 68 |

原因是 ADR-0007 記載的 `trades` 20 筆上限，疊加 ADR-0015 揭露的成交密度差距（熱門卡
20 筆只涵蓋 2 天，冷門卡可涵蓋 5 個月）。本地成交紀錄從第一輪成功爬取才開始累積，
往回推能算的卡種自然愈來愈少。

於是曲線的形狀有一半不是行情：**八月那段爬升，很大一部分是涵蓋率補齊造成的。**
不說出來的話，它會被讀成行情暴漲——而那正是使用者打開這張圖想回答的問題。

## Considered Options

**回填歷史資料**（否決）。以現有成交紀錄回填，三個月前僅 5/68 個持有卡種算得出市值，
畫出來的是一條說謊的線；以 SNKRDUNK 的 `chart` 欄位回填參考線技術上可行，可回溯至
2023-06-28，但需新表、新 ADR 與虛實兩段的視覺處理——**值得另開一票，但它不擋這張圖
現在就誠實**。

**涵蓋率不足就不畫**（否決）。曲線會從 2026-08 才開始，前面半年一片空白。而空白說的
是「沒有東西可看」，事實卻是「有東西可看，只是只涵蓋一部分」——這是把不完整說成不
存在。

**只把總市值除以涵蓋率、放大成全額估計**（否決）。這會編出一個沒有任何成交紀錄支撐
的數字，而且它看起來與真實的總市值一模一樣。ADR-0015 已經拒絕過同一個誘惑。

**照常計算並揭露涵蓋率**（採用）。數字本身沒有錯——它確實是「那一天我們手上算得出
市值的卡種」的總和；不足的是涵蓋率，而涵蓋率的形狀就寫在旁邊。這是唯一不需要改定義、
也不需要隱藏資料的作法。

## Consequences

- 走勢圖的每一個資料點一律附帶 `valued_kind_count` 與 `held_kind_count`。**完全沒有
  市值的卡種計入後者、不進總市值**——它確實是那天持有的卡，只是估不出價。

- 涵蓋率不足的區段必須在圖上看得出來，不能只寫在提示文字裡。目前的作法是曲線改虛線，
  並在橫軸下方附一條與曲線共用橫軸的涵蓋率量尺；視覺形式可由 UIUX 階段調整，**但
  「分得出來」這件事不可取消**。

- **涵蓋率會隨著每日爬取自己補齊**，不需要任何程式改動。今天的低涵蓋率區段是歷史的
  一次性缺口；從第一輪成功爬取（2026-08-26）之後的每一天，涵蓋率都是足額的。這條
  揭露義務**不會因此消失**——冷門卡種仍可能在某些日子算不出市值。

- 這條義務只約束走勢圖。單張卡的市值已由 ADR-0015 各自揭露樣本形狀，兩者不重複。
